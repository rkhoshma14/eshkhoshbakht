# ربات رنیم کانفیگ اشتراک

چند تا لینک اشتراک (subscription) بهش میدی، هرکدوم رو با یه اسم و یادداشت دلخواه
ذخیره می‌کنه، کانفیگ‌های داخلشونو پارس می‌کنه، و با هر اسمی که بخوای کانفیگ انتخابی
رو برات برمی‌گردونه.

پشتیبانی از فرمت‌های: `vmess`, `vless`, `trojan`, `ss`, و هر فرمت دیگه‌ای که بعد از
`#` اسم (remark) داشته باشه.

## استفاده

با `/start` یه منوی دکمه‌ای (Reply Keyboard) نشون داده میشه:

- **➕ افزودن اشتراک** — لینک رو می‌پرسه، بعد یه اسم (مثلا «آمریکا - محمد») و در آخر
  یه یادداشت اختیاری (یا زدن دکمه «بدون یادداشت»)
- **📋 لیست اشتراک‌ها** — لیست همه‌ی اشتراک‌های ذخیره‌شده رو نشون میده (هرکدوم با اسم
  و تعداد کانفیگ). روی هرکدوم بزنی، اسم و یادداشتش بالای صفحه نشون داده میشه و بعدش
  لیست کانفیگ‌های همون اشتراک با دکمه میاد. هرکدوم رو بزنی اسم جدید ازت پرسیده میشه
  و کانفیگ رنیم‌شده به صورت متن قابل کپی برمی‌گرده. توی همین صفحه این دکمه‌ها هم هست:
  - **📶 پینگ کانفیگ‌ها** — به همه‌ی کانفیگ‌های اون اشتراک به صورت موازی وصل میشه
    (TCP connect به آدرس و پورت هرکدوم) و نتیجه رو به میلی‌ثانیه، مرتب‌شده از سریع‌ترین
    به کندترین، برمی‌گردونه. کانفیگ‌هایی که وصل نشن «❌ تایم‌اوت» نشون داده میشن.
    توجه: این فقط سرعتِ برقراری اتصال TCP رو می‌سنجه، نه سرعت واقعی دانلود/آپلود از
    پشتِ VPN.
  - **📝 یادداشت** — هروقت بخوای می‌تونی یادداشت اون اشتراک رو عوض کنی یا حذفش کنی؛
    محدود به لحظه‌ی ساخت اشتراک نیست.
  - **🔄 بروزرسانی** — دوباره از روی لینک همون اشتراک، کانفیگ‌ها رو بروز می‌کنه
  - **« بازگشت به اشتراک‌ها**

## دیپلوی روی Railway

1. این پوشه رو به یک ریپازیتوری گیت‌هاب پوش کن.
2. توی Railway یک پروژه جدید بساز و از گزینه **Deploy from GitHub repo** همین ریپو رو انتخاب کن.
   Railway به خاطر وجود `Dockerfile` خودش تشخیص میده و بیلد می‌کنه.
3. توی تب **Variables** این متغیرها رو ست کن:
   - `BOT_TOKEN` — توکنی که از BotFather گرفتی
   - `ADMIN_IDS` — آیدی عددی تلگرام خودت (با کاما جدا کن اگه چندتا ادمین داری). اگه خالی
     بذاری همه می‌تونن از ربات استفاده کنن، پس حتما پرش کن.
   - `DB_PATH` — اختیاری، پیش‌فرض `data/bot.db`
4. یک **Volume** بساز و mount path رو بذار `/app/data` (همون مسیری که `DB_PATH` توش
   ذخیره میشه). بدون این Volume، با هر دیپلوی جدید دیتابیس (لینک اشتراک ذخیره‌شده) پاک میشه —
   دقیقا مثل کاری که برای پایداری Marzban روی Railway انجام دادی.
5. Deploy بزن. ربات با polling کار می‌کنه، پس نیازی به دامنه یا پورت باز نیست.

## نکته امنیتی

حتما `ADMIN_IDS` رو ست کن تا فقط خودت بتونی از ربات استفاده کنی، چون هرکسی که به
ربات پیام بده می‌تونه لینک اشتراک بذاره و کانفیگ‌هاشو ببینه.
